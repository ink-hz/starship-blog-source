## 二、核心心法

### 心法一：安全边际 (Margin of Safety)

**原文精华**：
> "安全边际的功能本质上可以概括为：你不需要准确估计公司的未来盈利。只要安全边际足够大，就足以保证投资者免受未来不确定性带来的损失。"

**白话解读**：
永远只在价格远低于内在价值时买入。就像过桥时，桥的承重能力是1万磅，但你只开5000磅的卡车过桥。即使你对桥的承重估计有误，多出来的5000磅余量也能保护你。安全边际是你对"自己可能犯错"这一事实的保险。

**在交易中的实际应用**：
- 买入时要求股价至少低于内在价值 33%（即以内在价值的 2/3 价格买入）
- 使用 PE x PB < 22.5 作为安全边际的量化门槛
- 估算内在价值时采用保守参数，预留 20%-30% 的缓冲空间

---

### 心法二：市场先生 (Mr. Market)

**原文精华**：
> "想象你与市场先生合伙经营一家企业。市场先生每天都会报出一个价格，他愿意以此价格买入你的股份或卖给你他的股份。有时他的报价合理，有时却荒谬至极。你完全可以自由地忽略他的报价。"

**白话解读**：
市场是一个情绪化的"合伙人"，它的报价有时合理有时疯狂。你的优势在于：你可以选择何时交易，而市场先生不行。当他恐慌时你买入，当他亢奋时你卖出，其他时候忽略他。不要被市场情绪牵着鼻子走。

**在交易中的实际应用**：
- 不因短期价格波动改变对基本面的判断
- 将市场下跌视为买入机会而非风险信号
- 设定明确的买入/卖出阈值，避免情绪化交易
- 定期（而非频繁）检查投资组合，减少噪音干扰

---

### 心法三：投资与投机的严格区分

**原文精华**：
> "投资操作是基于详尽的分析，确保本金的安全并能获得满意的回报。不符合这些要求的操作就是投机。"

**白话解读**：
买股票不是因为"感觉会涨"（投机），而是因为你算过这家公司值多少钱，当前价格明显低于这个值，且有足够的财务数据支持你的判断。如果你无法说出买入的具体理由和对应的估值逻辑，那你就是在投机。

**在交易中的实际应用**：
- 每次买入前必须完成估值分析（PE、PB、财务健康度等）
- 建立量化选股清单，不满足条件的股票一律不碰
- 区分"投资仓位"和"投机仓位"，投机资金不超过总资金的 5%-10%

---

### 心法四：逆向思维与情绪控制

**原文精华**：
> "在其他人都在卖出时买入，在其他人都在买入时卖出，这需要极大的意志力和判断力，但这正是获取超额收益的途径。"

**白话解读**：
当所有人都在买的时候要小心，当所有人都在恐慌抛售的时候要兴奋。这听起来简单，但执行极难，因为人类的本能是从众。格雷厄姆认为，聪明的投资者必须克服从众心理，在市场极端时保持冷静。

**在交易中的实际应用**：
- 当市场整体 PE 处于历史低位（如低于历史 20% 分位）时加大仓位
- 当市场整体 PE 处于历史高位（如高于历史 80% 分位）时减仓
- 建立逆向操作清单，在市场恐慌时自动筛选低估股票
- 保持日记记录，在重大交易时写下决策理由，避免事后合理化

---

### 心法五：分散投资与资产配置

**原文精华**：
> "即使投资者进行了充分的分析并应用了安全边际原则，仍然有可能出现判断错误。因此，适度的分散投资是必要的。"

**白话解读**：
再好的分析也可能出错，所以不要把所有鸡蛋放在一个篮子里。但分散也不是无限度的，格雷厄姆建议持有 10-30 只股票。同时，股票和债券之间要有一个基本的配置比例（如 50:50 到 75:25 之间），根据市场估值水平动态调整。

**在交易中的实际应用**：
- 单只股票仓位不超过总资金的 5%-10%
- 股票组合至少包含 10-15 只不同行业的股票
- 根据市场整体估值水平调整股债比例：
  - 市场低估时：股票 65%-75%，债券 25%-35%
  - 市场正常时：股票 50%-60%，债券 40%-50%
  - 市场高估时：股票 25%-35%，债券 65%-75%

## 三、可量化交易策略提取

### 策略一：防御型投资者七条选股法

| 项目 | 内容 |
|------|------|
| **来源章节** | 第14章《防御型投资者的股票选择》 |
| **策略类型** | 价值投资 / 基本面筛选 |
| **适用投资者** | 防御型（被动型）投资者 |

**入场条件（全部满足）**：

| 序号 | 条件 | 量化标准 | A股适用建议 |
|------|------|----------|------------|
| 1 | 适当的企业规模 | 年营收 >= 1亿美元（经通胀调整约7亿美元） | 年营收 >= 50亿人民币 |
| 2 | 强健的财务状况 | 流动比率 >= 2.0 | 流动比率 >= 2.0 |
| 3 | 盈利稳定性 | 过去10年每年盈利均为正 | 过去10年无亏损年度 |
| 4 | 股息记录 | 连续20年支付股息 | 连续5-10年分红（A股适当放宽） |
| 5 | 盈利增长 | 过去10年每股收益增长 >= 1/3（约33%） | 同左 |
| 6 | 适度的市盈率 | PE <= 15（基于过去3年平均盈利） | PE(TTM) <= 15 |
| 7 | 适度的市净率 | PB <= 1.5；综合条件：**PE x PB <= 22.5** | 同左 |

**出场条件**：
- 股价上涨至内在价值附近（安全边际消失）时卖出
- 公司基本面恶化，不再满足上述7条标准时卖出
- 持有期间定期（每季度/半年）复查

**止损规则**：
- 格雷厄姆不主张止损。若买入理由（基本面）未变，股价下跌反而应加仓
- 仅在公司基本面发生根本性恶化时卖出

**仓位管理建议**：
- 等权重配置，每只股票占总资金 5%-10%
- 组合持有 10-20 只股票
- 股票与债券比例为 25%-75% vs 75%-25%，根据市场估值动态调整

**适用市场环境**：熊市后期、市场恐慌期、经济复苏初期
**适用时间周期**：中长期持有（3-5年以上）

---

### 策略二：进取型投资者选股法

| 项目 | 内容 |
|------|------|
| **来源章节** | 第15章《进取型投资者的股票选择》 |
| **策略类型** | 深度价值 / 逆向投资 |
| **适用投资者** | 进取型（积极型）投资者 |

**入场条件（在防御型条件基础上放宽，但增加价值要求）**：

| 序号 | 条件 | 量化标准 |
|------|------|----------|
| 1 | 低市盈率 | PE <= 10（或不超过过去7年平均盈利的12倍） |
| 2 | 财务实力 | 流动资产 >= 流动负债的1.5倍 |
| 3 | 债务限制 | 债务不超过净流动资产的110% |
| 4 | 盈利稳定性 | 过去5-10年持续盈利 |
| 5 | 股息支付 | 当前有股息支付记录 |

**出场条件**：
- 股价回升至内在价值水平时卖出
- 公司连续两年无法恢复盈利时考虑卖出

**止损规则**：
- 单只股票最大亏损不超过组合的 5%
- 基本面分析错误时及时止损

**仓位管理建议**：
- 每只股票占总资金 3%-8%
- 组合可持有 15-30 只股票
- 可配置一定比例的低相关性资产（如可转债）

**适用市场环境**：市场低迷期、行业低谷期
**适用时间周期**：中期持有（1-3年）

### 策略三：净流动资产（Net-Net）策略

| 项目 | 内容 |
|------|------|
| **来源章节** | 第6章、第15章（便宜股票/特价股） |
| **策略类型** | 极端深度价值 / 资产套利 |
| **适用投资者** | 进取型投资者 |

**入场条件**：

| 序号 | 条件 | 量化标准 |
|------|------|----------|
| 1 | 核心条件 | 股价 < 每股净流动资产的2/3 |
| 2 | 净流动资产计算 | (流动资产 - 总负债 - 优先股) / 流通股数 |
| 3 | 无退市风险 | 公司仍在正常运营 |
| 4 | 流动性要求 | 有足够的日均成交量可交易 |

**出场条件**：
- 股价回升至每股净流动资产水平时卖出
- 持有超过2-3年仍未回升时重新评估

**止损规则**：
- 公司进入破产程序或资产严重缩水时止损

**仓位管理建议**：
- 分散到尽可能多的标的（20-30只以上）
- 单只股票仓位不超过 3%-5%
- 因为此类股票质量参差不齐，极度分散是必需的

**适用市场环境**：极端熊市、市场恐慌性抛售
**适用时间周期**：短中期（6个月-2年）

---

### 策略四：格雷厄姆数值选股法 (Graham Number)

| 项目 | 内容 |
|------|------|
| **来源章节** | 第11章、第14章 |
| **策略类型** | 价值投资 / 量化筛选 |
| **适用投资者** | 防御型和进取型投资者 |

**入场条件**：

| 序号 | 条件 | 量化标准 |
|------|------|----------|
| 1 | Graham Number > 股价 | 内在价值高于当前股价 |
| 2 | PE x PB <= 22.5 | 综合估值门槛 |

**Graham Number 计算公式**：

```
Graham Number = sqrt(22.5 x EPS x 每股净资产)
```

其中：
- 22.5 = 15（PE上限）x 1.5（PB上限）
- EPS = 过去12个月每股收益
- 每股净资产 = 股东权益 / 总股本

**买入信号**：当 股价 < Graham Number x 2/3 时买入（安全边际要求）

**出场条件**：
- 股价 >= Graham Number 时卖出
- EPS 持续恶化导致 Graham Number 大幅下降时卖出

**适用市场环境**：适用于估值分位较低的市场环境
**适用时间周期**：中长期（2-5年）

---

### 策略五：格雷厄姆成长股估值公式

| 项目 | 内容 |
|------|------|
| **来源章节** | 第11章 |
| **策略类型** | 成长价值投资 |

**原始公式**（1962年版）：

```
V = EPS x (8.5 + 2g)
```

**修订公式**（1974年版，加入利率因素）：

```
V = EPS x (8.5 + 2g) x (4.4 / Y)
```

参数说明：
- V = 内在价值
- EPS = 过去12个月每股收益
- 8.5 = 零增长公司的合理PE
- g = 预期未来7-10年的年化增长率（用百分比数值，如5%代入5）
- 4.4 = 1962年AAA级企业债券平均收益率
- Y = 当前AAA级企业债券收益率

**入场条件**：
- 股价 < V x 2/3（格雷厄姆要求2/3的安全边际）
- 修正版A股应用：Y可使用中国10年期国债收益率

**出场条件**：
- 股价 >= V 时考虑卖出
- 预期增长率 g 大幅下调时重新评估

**注意事项**（格雷厄姆本人警告）：
> "此公式仅供说明之用，不应被误认为具有高可靠性。未来价格并不一定会按照预测的增长率变化。"

**适用市场环境**：适合评估有一定增长但未被充分定价的股票
**适用时间周期**：中长期（3-7年）

---

### 策略六：股债动态平衡策略

| 项目 | 内容 |
|------|------|
| **来源章节** | 第4章《防御型投资者的通用组合策略》 |
| **策略类型** | 资产配置 / 再平衡 |

**核心规则**：

| 条件 | 操作 |
|------|------|
| 股票比例 > 75% | 卖出股票，买入债券，恢复至50:50或目标比例 |
| 股票比例 < 25% | 卖出债券，买入股票 |
| 正常范围 | 每年检查一次，进行再平衡 |

**量化执行标准**：
- 基准配置：股票50% + 债券50%
- 允许范围：股票25%-75%，根据市场估值动态调整
- 市场整体PE低于历史中位数时，股票比例上移至60%-75%
- 市场整体PE高于历史中位数时，股票比例下移至25%-40%
- 每年进行一次再平衡（定期而非频繁调整）

**适用市场环境**：所有市场环境
**适用时间周期**：长期（持续执行）

## 四、风险管理原则

### 1. 安全边际的量化定义

| 安全边际级别 | 量化标准 | 说明 |
|-------------|----------|------|
| **最低标准** | 股价 <= 内在价值的 2/3 | 格雷厄姆的基本要求，即安全边际 >= 33% |
| **严格标准** | 股价 <= 内在价值的 1/2 | 安全边际 >= 50%，适用于高风险股票 |
| **PE标准** | PE <= 15（3年平均盈利） | 防御型投资者的上限 |
| **PB标准** | PB <= 1.5 | 确保不溢价购买资产 |
| **综合标准** | PE x PB <= 22.5 | 同时控制盈利倍数和资产倍数 |
| **资产折扣** | 股价 <= 每股净有形资产的2/3 | 极端价值标准 |
| **净流动资产折扣** | 股价 <= 每股净流动资产 | Net-Net策略的极限标准 |

**安全边际的核心公式**：
```
安全边际 = (内在价值 - 买入价格) / 内在价值
建议最低安全边际 >= 33%（即以内在价值的67%或更低价格买入）
```

---

### 2. 分散投资原则

| 维度 | 格雷厄姆建议 | 说明 |
|------|-------------|------|
| **股票数量** | 10-30只 | 防御型10-15只，进取型可扩大到20-30只 |
| **行业分散** | 至少覆盖5个以上行业 | 避免单一行业风险 |
| **单只股票上限** | 不超过总资金的10% | 即使最看好的股票也需控制仓位 |
| **类型分散** | 股票+债券+现金 | 股债比例在25:75到75:25之间 |
| **地理分散** | — | 格雷厄姆时代主要投资美股，现代可适当全球化 |

---

### 3. 防御型 vs 进取型投资者的配置对比

| 维度 | 防御型投资者 | 进取型投资者 |
|------|-------------|-------------|
| **股票占比** | 25%-75%（建议50%） | 最高可达80% |
| **债券占比** | 25%-75%（建议50%） | 最低可至20% |
| **选股标准** | 严格遵循7条标准 | 可放宽标准但要求更大安全边际 |
| **股票质量** | 大型蓝筹、行业龙头 | 可包括次级质量股票（但必须极度便宜） |
| **研究投入** | 低，依赖简单筛选规则 | 高，需要深入分析个别公司 |
| **预期收益** | 市场平均或略高 | 追求超额收益 |
| **风险承受** | 低，优先保护本金 | 中高，愿意承受更大波动 |
| **持有周期** | 长期（5年以上） | 中长期（2-5年） |
| **再平衡频率** | 每年1次 | 每季度或根据机会 |
| **适合人群** | 大多数个人投资者 | 有时间研究市场的专业投资者 |

## 五、估值方法论

### 1. 格雷厄姆的估值公式体系

#### (1) Graham Number（格雷厄姆数值）

```
Graham Number = sqrt(22.5 x EPS x BVPS)
```

- EPS = 每股收益（过去12个月）
- BVPS = 每股账面价值（Book Value Per Share）
- 22.5 = 15（最大PE）x 1.5（最大PB）
- 当 股价 < Graham Number 时，股票被视为低估

#### (2) 原始成长股估值公式

```
V = EPS x (8.5 + 2g)
```

- 8.5 = 零增长公司的合理PE比率
- g = 预期未来7-10年年化增长率

#### (3) 修订版成长股估值公式（含利率因素）

```
V = EPS x (8.5 + 2g) x (4.4 / Y)
```

- 4.4 = 1962年AAA企业债券基准收益率
- Y = 当前AAA企业债券收益率（A股可用10年期国债收益率替代）

#### (4) 净流动资产价值 (Net Current Asset Value, NCAV)

```
NCAVPS = (流动资产 - 总负债 - 优先股) / 流通股数
```

买入标准：股价 <= NCAVPS x 2/3

---

### 2. 财务指标筛选标准

#### 防御型投资者 -- 完整筛选清单

| 序号 | 指标 | 标准 | 说明 |
|------|------|------|------|

| 3 | 连续盈利年数 | >= 10年 | 盈利稳定性 |

| 7 | PB | <= 1.5 | 资产估值合理 |

#### 进取型投资者 -- 完整筛选清单

### 3. "市场先生"概念的应用

**核心思想**：将市场视为一个情绪不稳定的合作伙伴，其报价（市场价格）只应作为参考，不应作为投资决策的依据。

**量化应用方法**：

| 市场状态 | 市场先生表现 | 投资者行动 | 量化信号 |
|----------|-------------|-----------|---------|
| 极度恐慌 | 大幅低于价值 | 大量买入 | 市场整体PE < 历史10%分位 |
| 恐慌 | 低于价值 | 适度买入 | 市场整体PE < 历史25%分位 |
| 正常 | 接近价值 | 持有 | 市场整体PE处于历史25%-75%分位 |
| 亢奋 | 高于价值 | 适度卖出 | 市场整体PE > 历史75%分位 |
| 极度亢奋 | 大幅高于价值 | 大量卖出 | 市场整体PE > 历史90%分位 |

#### A股市场特殊性对格雷厄姆策略的影响

1. **散户占比高**：市场情绪波动更大，为价值投资者提供更多极端低估机会
2. **政策驱动明显**：需要结合政策面分析，纯量化指标可能不足
3. **周期性行业占比高**：银行、地产、资源等周期股PE低可能是"价值陷阱"
4. **市场效率较低**：定价效率不如美股，价值发现需要更长时间
5. **财务数据质量**：需要更加审慎地审查财务报表真实性

### 2. 如何结合基本面筛选和量化模型

#### 建议的量化筛选流程

```
第一层：格雷厄姆基础筛选
├── PE(TTM) <= 15
├── PB <= 1.5
├── PE x PB <= 22.5
├── 流动比率 >= 2.0
├── 连续5年以上盈利为正
└── 连续3年以上分红

第二层：财务健康度检查
├── 资产负债率 < 60%（非金融企业）
├── ROE >= 8%（连续3年以上）
├── 经营现金流/净利润 >= 0.7
└── 商誉/净资产 < 20%

第三层：估值确认
├── Graham Number = sqrt(22.5 x EPS x BVPS)
├── 股价 < Graham Number（低估）
├── 修订Graham公式 V = EPS x (8.5 + 2g) x (4.4/Y)
└── 股价 < V x 0.67（安全边际确认）

第四层：行业与宏观过滤
├── 排除强周期行业低谷中的"价值陷阱"
├── 检查行业景气度趋势
└── 结合宏观政策面确认
```

#### 量化回测建议参数

| 参数 | 建议值 | 说明 |
|------|-------|------|
| 调仓频率 | 半年或年度 | 降低交易成本，符合价值投资理念 |
| 回测区间 | >= 10年 | 覆盖至少一个完整的牛熊周期 |
| 基准指数 | 沪深300或中证500 | 根据选股范围选择 |
| 交易成本 | 单次0.15%（含佣金+滑点） | A股实际交易成本 |
| 涨跌停限制 | 考虑涨停无法买入、跌停无法卖出 | A股特殊规则 |

### 3. 格雷厄姆指标在A股的回测表现

根据华证指数研究报告《格雷厄姆价值投资思想的A股实践》的数据：

| 策略 | 年化收益 | 波动率 | 说明 |
|------|---------|--------|------|
| **经典价值策略** | 10.43% | 23.22% | 基于PE、PB等经典价值因子 |
| **深度价值策略** | 11.34% | 24.45% | 更严格的低估标准 |
| **沪深300基准** | 约7%-8% | 约22% | 同期基准对比 |

#### 关键发现

1. **低PE/PB策略长期有效**：在A股历史回测中，低PE/PB组合长期跑赢市场
2. **深度价值波动更大**：更严格的低估标准带来更高收益，但波动也更大
3. **烟蒂指标（PB x PE）**：在沪深300成分股选股中表现突出
4. **价值因子的周期性**：价值策略在某些时段（如成长股牛市）可能跑输市场
5. **A股特色调整**：
   - 分红标准需要适当放宽（从20年降至5-10年）
   - 企业规模标准需要重新定义（使用人民币计价）
   - 利率基准使用中国10年期国债收益率替代AAA企业债券收益率
   - 需要排除周期性行业的"价值陷阱"

#### 实际A股量化实现注意事项

- **数据源**：使用TTM财务数据，避免使用单季度数据导致失真
- **负PE处理**：PE为负（亏损）的公司直接排除
- **金融行业**：银行、保险等金融行业的PB标准和负债率标准需单独设定
- **ST/退市风险**：需要加入ST标记和退市风险过滤
- **行业中性化**：建议在行业内部进行相对排序，避免行业集中度问题
