# 【交易圣经】《以交易为生》三重滤网系统把交易从艺术变成工程

## 一、书籍基本信息

| 项目 | 内容 |
|------|------|
| **书名** | 《以交易为生》（Trading for a Living） |
| **作者** | 亚历山大·埃尔德（Alexander Elder, M.D.） |
| **首版年份** | 1993年；第二版《The New Trading for a Living》于2014年出版 |
| **作者背景** | 出生于列宁格勒（现圣彼得堡），23岁移居美国。精神病学医学博士，曾在纽约从事精神科医生工作多年，后转型为职业交易者、交易教练和作家 |
| **核心理念** | 交易成功的三大基石：**心理（Mind）、方法（Method）、资金管理（Money）**——简称"3M"体系。其中心理是基础，资金管理是生存之本，方法是获利手段 |
| **市场定位** | 全球交易类经典畅销书，被翻译成十余种语言，累计销量超过50万册 |

## 二、核心心法

### 心法一：交易是心理游戏

**原文精华转述：**
> "Beginners focus on analysis, but professionals operate in a three-dimensional space. They are aware of trading psychology, their own feelings, and the mass psychology of the markets."
> （初学者专注于分析，而专业人士在三维空间中运作——他们同时关注交易心理、自身情绪和市场群体心理。）

**白话解读：**
Elder作为精神病医生，深刻揭示了交易的本质——不是与市场搏斗，而是与自己的内心搏斗。恐惧和贪婪是交易的两大敌人。大多数亏损不是因为分析方法不好，而是因为执行时被情绪绑架。市场本身并不知道你的存在，你唯一能控制的就是自己的行为。

**在交易中的实际应用：**
- 每次交易前自问："我现在的决策是基于分析还是基于情绪？"
- 当连续盈利时警惕过度自信，当连续亏损时警惕恐惧性退缩
- 将交易视为一门纪律性的职业，而非刺激的赌博

---

### 心法二：与群体保持距离

**原文精华转述：**
> "Markets are actually set up so that most traders must lose money."
> （市场的设计使得大多数交易者必然会亏损。）

**白话解读：**
市场本质上由群体心理驱动——群体在顶部时最乐观（贪婪），在底部时最悲观（恐惧）。要想盈利，交易者必须有意识地与群体保持距离，做独立思考的"少数派"。Elder将市场中的报价机比作"催眠师"，不断向交易者发出暗示，只有保持清醒的人才能抵御这种催眠。

**在交易中的实际应用：**
- 在所有人都在买入时保持警惕，在所有人都在恐慌抛售时寻找机会
- 不看财经媒体的"噪音"，按自己的交易系统行事
- 记录每次被群体情绪影响的交易，建立自我觉察

---

### 心法三：先防守后进攻——资金管理是生存之本

**原文精华转述：**
> "A good trader watches his capital as carefully as a professional scuba diver watches his air supply."
> （一个好的交易者看护自己的资金，就像专业的潜水员看护自己的氧气供应一样。）

**白话解读：**
即使你拥有最好的交易系统，如果没有资金管理，一次连续亏损就能让你出局。Elder反复强调：资金管理不是可选的附加项，而是交易成功的决定性因素。先学会不亏钱，再学会赚钱。

**在交易中的实际应用：**
- 严格执行2%规则和6%规则（详见第五节）
- 永远不要让单笔亏损威胁到账户的生存
- 仓位大小由风险决定，而非由"我觉得能赚多少"决定

---

### 心法四：多重验证，拒绝单一指标依赖

**原文精华转述：**
> "To win you have to trade with an edge and execute your trades flawlessly."
> （要赢，你必须带着优势交易，并无缺陷地执行。）

**白话解读：**
没有任何单一指标能在所有市场环境下可靠工作。趋势指标在趋势市场中好用，但在震荡市场中反复发出错误信号；振荡指标在震荡市场中好用，但在趋势市场中过早退出。三重滤网系统的精髓就是用不同类别的指标相互验证，取长补短。

**在交易中的实际应用：**
- 用趋势指标判断方向，用振荡指标寻找入场时机
- 从多个时间框架分析同一笔交易
- 不追求"完美指标"，追求"多重验证"的交易系统

---

### 心法五：交易日记是成长的阶梯

**原文精华转述：**
> "Keep a trading diary—write down your reasons for entering and exiting every trade. Look for repetitive patterns of success and failure."
> （坚持写交易日记——记录你进入和退出每笔交易的理由。寻找成功和失败中反复出现的模式。）

**白话解读：**
交易日记不是简单的盈亏记录，而是自我认知的工具。通过详细记录每笔交易的决策过程、情绪状态和市场环境，你才能发现自己的优势在哪里、弱点在哪里。Elder要求记录的内容极其详细，包括入场理由、止损位、目标位、最大浮盈、最大浮亏、佣金、滑点等。

**在交易中的实际应用：**
- 每笔交易记录：买入/卖出日期、价格、止损位、调整止损的记录、买入原因、目标价
- 记录交易时的情绪状态（焦虑/兴奋/恐惧/平静）
- 每周/月回顾日记，识别重复的亏损模式和盈利模式
- 将日记分为"交易记录"和"心理记录"两部分

## 三、三重滤网交易系统（核心）

这是Elder对交易领域最重要的策略贡献，首次发表于1986年的《Futures Magazine》，后在《以交易为生》中系统阐述。

### 设计哲学

核心思想来源于医学的"三重筛查"概念——通过三层递进的筛选，逐层过滤掉不合格的交易机会。每一层筛掉一部分错误信号，三层叠加后留下的就是高质量的交易机会。

**关键原则：每一层筛查如果不通过，就立即放弃，不进入下一层。**

### 时间框架的选择

三重滤网系统的基础是**多时间框架分析**。Elder建议时间框架之间保持约**5倍**的关系：

| 交易者类型 | 长期框架（第一层） | 中期框架（第二层） | 短期框架（第三层） |
|-----------|------------------|------------------|------------------|
| **波段交易者**（默认） | 周线图（Weekly） | 日线图（Daily） | 4小时图（H4）或日内 |
| **日内交易者** | 日线图（Daily） | 4小时图（H4）或1小时图（H1） | 15分钟图（M15）或更短 |
| **长线交易者** | 月线图（Monthly） | 周线图（Weekly） | 日线图（Daily） |

**比喻体系：**
- **潮汐（Tide）**= 长期趋势（周线）
- **波浪（Wave）**= 中期波动（日线）
- **涟漪（Ripple）**= 短期波动（小时线/分钟线）

> "在潮汐方向上交易，利用波浪寻找入场点，忽略涟漪中的噪音。"

---

### 第一层滤网：市场潮汐（识别趋势方向）

**目的：** 确定长期趋势方向，决定只做多还是只做空。

**使用图表：** 长期时间框架（如周线图）

**推荐指标及参数：**

| 指标 | 参数 | 用法 |
|------|------|------|
| **MACD**（默认推荐） | 快线12周、慢线26周、信号线9周 | MACD柱状图（Histogram）是核心观察对象 |
| **指数移动平均线（EMA）** | 26周EMA | 价格在EMA之上且EMA上升=上升趋势 |
| **趋势线** | 手动画线 | 用于辅助判断 |

**做多条件（周线图）：**
1. MACD柱状图**从负值区域向上翻转**（即本周的MACD-H > 上周的MACD-H），或者
2. MACD线从下向上穿越信号线（金叉），或者
3. 价格位于上升的26周EMA之上

**做空条件（周线图）：**
1. MACD柱状图**从正值区域向下翻转**（即本周的MACD-H < 上周的MACD-H），或者
2. MACD线从上向下跌穿信号线（死叉），或者
3. 价格位于下降的26周EMA之下

**关键规则：**
> 如果周线趋势向上，**只允许寻找做多机会**，忽略所有做空信号。
> 如果周线趋势向下，**只允许寻找做空机会**，忽略所有做多信号。

---

### 第二层滤网：市场波浪（寻找回调入场点）

**目的：** 在第一层确认的趋势方向上，等待回调（逆趋势的短期波动），利用振荡指标识别回调何时结束。

**使用图表：** 中期时间框架（如日线图）

**推荐指标及参数：**

| 指标 | 参数 | 核心用法 |
|------|------|---------|
| **强力指数（Force Index）** | 2日EMA（短期）或13日EMA（中期） | 捕捉短期回调的极端值 |
| **Elder-Ray（牛力/熊力）** | 13日EMA作为基准线 | 熊力为负且上升=买入；牛力为正且下降=卖出 |
| **随机振荡器（Stochastic）** | %K=5, %D=3, 平滑=3 | 超卖区（<20%）回升=买入信号 |
| **威廉指标（Williams %R）** | 14日 | 超卖区回升=买入信号 |

**做多时的第二层信号（日线图，周线趋势向上）：**
1. 等待日线级别的**回调下跌**
2. **Force Index（2日EMA）**跌入负值区域（说明短期有抛压）
3. **Elder-Ray熊力指标**为负值（价格跌至EMA之下）
4. **随机振荡器**跌至20%以下的超卖区
5. 当上述指标**开始回升**时，说明回调可能即将结束——这是潜在入场区域

**做空时的第二层信号（日线图，周线趋势向下）：**
1. 等待日线级别的**反弹上涨**
2. **Force Index（2日EMA）**升入正值区域（说明短期有买盘）
3. **Elder-Ray牛力指标**为正值（价格涨至EMA之上）
4. **随机振荡器**升至80%以上的超买区
5. 当上述指标**开始回落**时，说明反弹可能即将结束——这是潜在做空区域

**核心理念：**
> "最佳买入机会出现在上升市场短暂下跌的时候；最佳做空机会出现在下跌市场短暂上涨的时候。"

---

### 第三层滤网：精准入场（确定具体买卖点）

**目的：** 在前两层确认方向和时机后，在短期时间框架上确定精确的入场价格。

**使用图表：** 短期时间框架（如4小时图或1小时图）

**入场方法——追踪止损单（Trailing Stop）：**

**做多入场（周线上升 + 日线回调结束）：**
1. 在日线回调结束的信号出现后，切换到短期图表（如4小时图）
2. 在前一日最高价之上**一个tick（最小价格单位）**设置**追踪买入止损单（Buy Stop）**
3. 如果价格上涨触发止损单，自动入场做多
4. 如果价格继续下跌未触发，则将止损单**下移**至新一日最高价之上一个tick
5. 持续追踪，直到触发入场或周线趋势改变

**做空入场（周线下降 + 日线反弹结束）：**
1. 在日线反弹结束的信号出现后，切换到短期图表
2. 在前一日最低价之下**一个tick**设置**追踪卖出止损单（Sell Stop）**
3. 如果价格下跌触发止损单，自动入场做空
4. 如果价格继续上涨未触发，则将止损单**上移**至新一日最低价之下一个tick
5. 持续追踪，直到触发入场或周线趋势改变

**替代入场方法：**
- 利用短期图表上的支撑/阻力位突破
- 利用短期图表上的K线形态确认（如锤子线、吞没形态）
- 利用短期EMA交叉确认

---

### 完整的交易流程示例

**假设场景：波段交易者，交易某A股股票**

**第一步：周线图分析（第一层滤网）**
- 打开周线图，查看MACD指标（12, 26, 9）
- 发现MACD柱状图上周为-0.15，本周为-0.08，正在从负值区域向上收窄
- MACD线在信号线下方但差距缩小，即将形成金叉
- **结论：周线趋势即将转为上升，准备寻找做多机会**

**第二步：日线图分析（第二层滤网）**
- 切换到日线图，查看随机振荡器（5, 3, 3）
- 股票在过去5天持续回调，随机振荡器跌至15%（超卖区）
- Force Index（2日EMA）为负值，且开始回升
- Elder-Ray熊力指标为-0.8，但正在缩小（从-1.2回升）
- **结论：日线回调即将结束，准备入场做多**

**第三步：短期图表执行（第三层滤网）**
- 切换到60分钟图
- 前一日最高价为25.30元
- 设置追踪买入止损单：25.31元（25.30 + 0.01）
- 设定止损位：日线近期低点24.50元下方，如24.40元
- **若价格涨至25.31元，自动入场做多**

**第四步：风控与出场**
- 计算仓位：假设账户10万元，2%风险=2000元
  - 入场25.31，止损24.40，每手风险=0.91元
  - 可买入股数=2000/0.91=2197股，取整2000股（2手）
- 移动止损：随着价格上涨，逐步将止损上移至近期日线低点
- 出场信号：日线MACD柱状图开始下降，或Force Index出现顶背离

---

### 每一层的具体参数建议汇总

| 滤网层级 | 时间框架 | 核心指标 | 关键参数 | 决策内容 |
|---------|---------|---------|---------|---------|
| **第一层** | 周线 | MACD柱状图 | 12, 26, 9 | 趋势方向（只做多或只做空） |
| **第一层** | 周线 | EMA | 26周 | 辅助趋势判断 |
| **第二层** | 日线 | Force Index | 2日EMA | 回调极端值识别 |
| **第二层** | 日线 | Elder-Ray | 13日EMA基准 | 牛力/熊力判断 |
| **第二层** | 日线 | 随机振荡器 | 5, 3, 3（超卖<20%，超买>80%） | 超买超卖确认 |
| **第三层** | 4H/1H | 追踪止损单 | 前日最高/最低价+1tick | 精确入场执行 |

## 四、其他可量化交易策略

### 策略一：冲动系统（Impulse System）

| 项目 | 内容 |
|------|------|
| **来源章节** | 《以交易为生》技术分析章节；在《走进我的交易室》中有更详细阐述 |
| **策略类型** | 趋势跟踪 + 动量确认 |
| **核心组成** | 13日EMA（趋势方向）+ MACD柱状图（12, 26, 9）（动量方向） |
| **做多信号** | EMA上升 **且** MACD柱状图上升 = 绿色冲动（看涨） |
| **做空信号** | EMA下降 ** 且** MACD柱状图下降 = 红色冲动（看跌） |
| **中性信号** | EMA和MACD柱状图方向不一致 = 蓝色/中性（不交易，收紧止损） |
| **入场条件** | 仅在绿色冲动阶段做多；仅在红色冲动阶段做空 |
| **出场条件** | 从绿色变为蓝色时收紧止损或部分平仓；从红色变为蓝色时同理 |
| **止损规则** | 中性信号时移动止损至近期支撑/阻力位 |
| **仓位管理** | 配合2%规则计算仓位 |

**量化应用：** 此策略可直接编码为指标——计算EMA斜率方向和MACD-H变化方向，两者同向时输出信号。适合作为交易系统的过滤器使用。

---

### 策略二：Elder-Ray系统（牛力/熊力指标）

| 项目 | 内容 |
|------|------|
| **来源章节** | 《以交易为生》独创指标章节 |
| **策略类型** | 震荡指标 / 回调入场系统 |
| **核心公式** | 牛力（Bull Power）= 当日最高价 - 13日EMA；熊力（Bear Power）= 当日最低价 - 13日EMA |
| **做多入场条件** | (1) EMA上升（趋势向上）；(2) 熊力为负值（价格回调至EMA下方）；(3) 熊力从负值开始回升（空头力量减弱） |
| **做空入场条件** | (1) EMA下降（趋势向下）；(2) 牛力为正值（价格反弹至EMA上方）；(3) 牛力从正值开始回落（多头力量减弱） |
| **出场条件** | 牛力/熊力出现背离时出场（如价格创新高但牛力未创新高） |
| **止损规则** | 入场后将止损设在近期极值之外（做多时设在熊力最低点对应的K线低点下方） |
| **仓位管理** | 配合2%规则 |

**量化应用：** 每日计算Bull Power和Bear Power，当满足上述三重条件时生成交易信号。可与MACD趋势判断结合使用。

---

### 策略三：强力指数（Force Index）

| 项目 | 内容 |
|------|------|
| **来源章节** | 《以交易为生》独创指标章节 |
| **策略类型** | 量价结合振荡指标 |
| **核心公式** | Force Index = (今日收盘价 - 昨日收盘价) x 今日成交量 |
| **参数** | 2日EMA（短期信号）或13日EMA（中期信号） |
| **做多信号** | 2日Force Index从负值转为正值（短期回调结束确认） |
| **做空信号** | 2日Force Index从正值转为负值（短期反弹结束确认） |
| **背离交易** | 价格创新高但13日Force Index未创新高 = 看跌背离（卖出）；价格创新低但13日Force Index未创新低 = 看涨背离（买入） |
| **出场条件** | Force Index背离出现时准备出场 |
| **止损规则** | 根据入场位的近期支撑/阻力设置 |
| **仓位管理** | 配合2%规则 |

**量化应用：** Force Index将价格变化和成交量统一为一个数值，可通过EMA平滑后检测背离。可用代码自动检测价格与Force Index之间的背离关系。

|------|------|

## 五、资金管理原则

Elder将资金管理视为交易成功的"三大支柱"之一，并提出两条铁律。

### 5.1 核心铁律一：2%规则（单笔风险上限）

**定义：** 每一笔交易的最大允许亏损不超过账户总资金的**2%**。

**具体含义：**
- 这2%包括**从入场价到止损价之间的差价**乘以持仓数量
- 不是指用2%的资金去买股票，而是指**如果止损被触发，你最多只亏2%**

**计算公式：**
```
最大允许亏损金额 = 账户总资金 x 2%

可买入股数 = 最大允许亏损金额 / (入场价 - 止损价)
```

**计算示例：**
- 账户总资金：500,000元
- 2%风险上限：10,000元
- 计划买入股票：入场价25.50元，止损价24.50元
- 每股风险：25.50 - 24.50 = 1.00元
- 可买入股数：10,000 / 1.00 = 10,000股
- 需要资金：10,000 x 25.50 = 255,000元（占账户51%）
- 但如果止损，亏损仅为10,000元（账户的2%）

**核心要点：**
> 止损位由市场结构决定（支撑位/阻力位），而非由2%规则决定。2%规则决定的是**仓位大小**，不是止损位。

---

### 5.2 核心铁律二：6%规则（月度风险上限）

**定义：** 在任何一个月份内，所有持仓的总风险敞口（以及已实现的月度亏损之和）不超过账户总资金的**6%**。

**具体操作：**
1. 每月初重置计数器
2. 每开一笔新仓，将这笔交易的风险金额加入月度风险总计
3. 当月度风险总计达到账户的6%时，**停止开新仓**
4. 如果当月实际亏损（已止损平仓的亏损）达到6%，**当月停止所有交易**，下个月再重新开始

**示例：**
- 账户总资金：500,000元
- 6%月度上限：30,000元
- 第一笔交易风险：10,000元（2%）→ 月度风险余额：20,000元
- 第二笔交易风险：8,000元 → 月度风险余额：12,000元
- 第三笔交易风险：12,000元 → 月度风险余额：0元，**停止开新仓**
- 如果前两笔交易都止损（亏损18,000元），月度实际亏损已达18,000元
- 第三笔交易风险12,000元 → 18,000 + 12,000 = 30,000 = 6%，**可以开仓但不再增加**

**意义：**
> 2%规则管单笔，6%规则管全局。两条规则配合使用，确保即使在最糟糕的月份，账户也不会遭受毁灭性打击。

---

### 5.3 仓位计算完整方法

**步骤一：确定入场价和止损价**
- 由技术分析决定（支撑位、近期低点等）

**步骤二：计算每股风险**
```
每股风险 = |入场价 - 止损价|
```

**步骤三：计算最大允许亏损**
```
最大允许亏损 = 账户资金 x 2%
```

**步骤四：计算可买入股数**
```
可买股数 = 最大允许亏损 / 每股风险
（向下取整至整手）
```

**步骤五：验证6%规则**
```
月度风险总计 + 本次风险 <= 账户资金 x 6%
```

## 六、交易心理学

### 6.1 群体心理 vs 个人纪律

Elder的核心洞察来自其精神病学背景：

**市场的群体心理特征：**
- **群体在顶部时最乐观**：媒体纷纷看好，散户疯狂涌入，"这次不一样"的论调盛行
- **群体在底部时最悲观**：恐慌蔓延，割肉离场，"市场要完了"的声音此起彼伏
- **群体行为具有传染性**：报价机的每一次跳动都在传递情绪，如同催眠师的暗示
- **群体不思考，只反应**：追涨杀跌是群体行为的典型模式

**个人纪律的建立：**
- **制定交易计划并严格执行**——进场前写好入场点、止损点、目标位
- **与群体保持心理距离**——不因别人的贪婪而兴奋，不因别人的恐惧而动摇
- **承认自己的情绪但不受其驱使**——Elder将此比作AA（匿名戒酒会）的方法，第一步就是承认问题

### 6.2 常见心理陷阱及应对

| 心理陷阱 | 表现 | Elder的应对建议 |
|---------|------|----------------|
| **过度自信** | 连续盈利后加大仓位、放松止损 | 连赢后更要严格遵守规则，不改变系统 |
| **赌徒心理** | 亏损后急于翻本、频繁交易 | 启动6%规则强制休息，远离市场 |
| **后悔与幻想** | "要是当时没卖就好了"、"肯定会涨回来的" | 专注当下决策，不浪费精力在后悔上 |
| **权威依赖** | 盲目跟随"大师"推荐 | 建立自己的交易系统，独立做决策 |
| **证实偏差** | 只看到支持自己观点的信息 | 主动寻找反面证据，定期审视持仓理由 |
| **害怕错过（FOMO）** | 看到别人赚钱就急于入场 | 记住"错过机会不亏钱，错误入场才亏钱" |
| **希望心理** | 亏损时不认赔，期待"会回来的" | 止损是保护，不是认输 |

### 6.3 交易日记的价值

Elder极度重视交易日记，将其视为交易者的"成长日志"。他认为坚持写交易日记是区分业余者和专业人士的关键行为之一。

**交易日记必须包含的内容：**
1. **交易基本信息**：买入/卖出的日期、价格、数量
2. **交易理由**：为什么买入/卖出，技术信号是什么
3. **止损位**：初始止损位及所有调整记录
4. **目标价位**：预期盈利目标
5. **滑点与佣金**：实际交易成本
6. **最大浮盈与最大浮亏**：交易过程中的极值
7. **情绪状态**：入场时和持仓中的心理状态
8. **教训总结**：这笔交易做对了什么，做错了什么

**日记的使用方法：**
- 每周做一次回顾，寻找重复模式
- 每月做一次统计：胜率、盈亏比、最大回撤、最常犯的错误
- 每季度做一次深度复盘：系统是否需要调整、心理是否有进步

## 八、与现代交易的关联

### 8.1 三重滤网系统在A股的适用性

**A股的特殊性：**
- T+1交易制度（当天买入次日才能卖出）——影响第三层滤网的执行方式
- 涨跌停限制（主板10%，创业板/科创板20%）——影响止损的执行
- 散户占比高，群体心理效应更明显——Elder的心理学分析在A股更适用
- 融券限制较多——做空相对困难，三重滤网的做空端需要调整

**适用性评估：**
- **做多端**：高度适用。A股的散户结构使得趋势一旦形成往往延续性较强，在周线趋势向上时利用日线回调买入的策略非常有效。
- **做空端**：可通过融券（如有券源）或股指期货/期权间接实现，但操作门槛较高。
- **资金管理端**：2%和6%规则完全适用于A股，且因为A股波动性较大，这两条规则尤为重要。

### 8.2 参数调整建议

针对A股市场的特点，建议以下参数调整：

| 参数 | 原始值 | A股建议调整 | 原因 |
|------|--------|-----------|------|
| 第一层EMA | 26周 | 20-26周均可 | A股趋势切换较快，可适当缩短 |
| MACD | 12, 26, 9 | 保持不变或用8, 21, 5 | A股常用的MACD参数略有差异 |
| 随机振荡器 | 5, 3, 3 | 9, 3, 3 | A股波动大，稍长周期可减少假信号 |
| Force Index | 2日/13日 | 3日/13日 | 因T+1限制，2日太短，建议3日 |
| 通道宽度 | 2-3% | 3-5% | A股波动率高于美股，通道需更宽 |
| 止损幅度 | 不固定 | 参考ATR的1.5-2倍 | 根据个股波动率动态调整 |

### 8.3 与现代量化框架的结合

三重滤网系统天然适合量化实现，以下是编码层面的映射：

**数据层：**
```
# 时间框架数据获取
weekly_data = resample(daily_data, 'W')  # 周线数据
daily_data = daily_data                    # 日线数据
intraday_data = resample(daily_data, '4H')  # 4小时数据
```

**第一层信号生成：**
```python
# MACD柱状图方向判断
weekly_data['MACD'], weekly_data['Signal'], weekly_data['MACD_H'] = MACD(weekly_data['close'], 12, 26, 9)
weekly_trend = 'UP' if weekly_data['MACD_H'].diff() > 0 else 'DOWN'
```

**第二层信号生成：**
```python
# Force Index计算
daily_data['FI'] = (daily_data['close'].diff() * daily_data['volume']).ewm(span=2).mean()
# Stochastic计算
daily_data['K'], daily_data['D'] = stochastic(daily_data, 5, 3)
# 买入回调信号
pullback_buy = (weekly_trend == 'UP') & (daily_data['FI'] < 0) & (daily_data['K'] < 20)
```

**第三层执行逻辑：**
```python
# 追踪买入止损单
entry_price = daily_data['high'].shift(1) + tick_size
if current_price >= entry_price and pullback_buy:
    execute_buy(position_size=calculate_position(account, entry_price, stop_loss, risk_pct=0.02))
```

**资金管理模块：**
```python
def calculate_position(account_value, entry_price, stop_loss, risk_pct=0.02):
    max_loss = account_value * risk_pct
    per_share_risk = abs(entry_price - stop_loss)
    shares = int(max_loss / per_share_risk)
    return shares

def check_monthly_risk(account_value, monthly_risk_used, new_trade_risk):
    max_monthly_risk = account_value * 0.06
    return (monthly_risk_used + new_trade_risk) <= max_monthly_risk
```
