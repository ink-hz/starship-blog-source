## 总纲：五大共识

五本书横跨百年，作者背景迥异——投机大师、价值投资之父、17位顶尖交易员、精神病医生、交易心理学家——但底层共识惊人地一致：


## 心法一：风控至上——活着才有输出

> "截断亏损，让利润奔跑。"——这是五本书中唯一被所有人重复的观点。

### 核心原则

| 原则 | 量化规则 | 来源 |
|------|---------|------|
| 单笔最大亏损 | ≤ 账户净值的 **1%-2%** | Larry Hite、Elder 2%规则、Tharp |
| 月度最大亏损 | ≤ 账户净值的 **6%** | Elder 6%规则 |
| 持仓总风险 | ≤ 账户净值的 **5%-10%** | Kovner、Hite |
| 强制止损线 | 任何持仓亏损达 **7%-10%** 无条件清仓 | Livermore、O'Neil |
| 永不摊平 | 亏损头寸**绝不在加仓** | Livermore、Jones："输家才会加仓输家" |

### 止损方法矩阵

| 方法 | 规则 | 适用场景 | 来源 |
|------|------|---------|------|
| 固定百分比 | 买入价下方 7%-8% | 成长股、技术交易 | O'Neil |
| 波动率自适应 | 2倍 ATR | 趋势跟踪、期货 | Dennis（N值系统） |
| 关键点止损 | 突破点下方 2-3% | 突破策略 | Livermore |
| 移动止损 | 盈利>5%后移至盈亏平衡 | 所有趋势持仓 | Livermore |
| 时间止损 | 5-10日未按预期运动则离场 | 短中线交易 | Livermore |

### 风控铁律

```
1. 入场前必须确定止损价位（Kovner："入场前就知道在哪里离场"）
2. 止损一旦设定，不因情绪移动或取消
3. 止损触发时立即执行，不分析"为什么"（Jones）
4. 盈利超5%后移动止损至盈亏平衡点
5. 盈利超10%后移动止损锁定至少一半利润
6. 连亏3笔 → 缩仓至正常仓位的50%
7. 月度亏损达6% → 当月停止交易
```

## 心法二：仓位为王——决定盈亏的不是方向，是仓位

> Tharp 的经典实验证明：随机入场 + 科学仓位管理 > 精确入场 + 糟糕仓位管理。

### R倍数体系

```
R = |入场价 - 止损价| × 持仓数量       （每笔交易的初始风险）
R倍数 = 实际盈亏 / R                    （以R为单位衡量结果）
```

| 交易结果 | 含义 | 判断 |
|----------|------|------|
| <-1R | 亏损超过初始风险 | **违反规则！** |
| -1R | 恰好止损 | 正常亏损 |
| +1R | 盈利等于风险 | 保底盈利 |
| +2R~+3R | 良好盈利 | 目标区间 |
| +5R 以上 | 大赢交易 | 财富来源 |

### 期望值公式

```
期望值 = (胜率 × 平均盈利R) + (败率 × 平均亏损R)
```

**核心认知转变**：从"这笔对不对"→ 到"长期执行这个系统每笔平均赚多少R"

| 系统类型 | 典型胜率 | 典型盈亏比 | 期望值 | 说明 |
|----------|---------|-----------|--------|------|
| 趋势跟踪 | 35%-45% | 3:1 | +0.3R~+0.7R | 少赢大赢 |
| 均值回归 | 55%-65% | 1.2:1 | +0.2R~+0.4R | 多赢小赢 |
| 成长股选股 | 40%-50% | 2.5:1 | +0.3R~+0.5R | 中等胜率中大赢 |

### 仓位计算方法

**固定分数法（最实用）：**
```
买入股数 = (账户净值 × 每笔风险比例) / |入场价 - 止损价|
```

**波动率调仓法（进阶）：**
```
买入股数 = (账户净值 × 每笔风险比例) / (ATR × ATR倍数)
```
高波动品种自动减仓，低波动品种自动加仓，实现跨品种风险等价。

**反马丁格尔原则：**
- 盈利后增加仓位（乘胜追击）
- 亏损后减小仓位（保护资本）
- 回撤10% → 仓位降至75%；回撤15% → 降至50%；回撤20% → 降至25%

### 回撤与回本（数学现实）

| 回撤幅度 | 回本所需涨幅 | 启示 |
|----------|-------------|------|
| 10% | 11% | 可控 |
| 20% | 25% | 需警惕 |
| 30% | 43% | 困难 |
| 50% | 100% | 需翻倍 |
| 75% | 300% | 几乎绝望 |

**结论：控制回撤比追求收益更重要。**

## 心法三：顺势而为——不与市场作对

> "股市只有一面，不是牛市的一面或熊市的一面，而是正确的一面。"——Livermore

### 多时间框架分析（Elder 三重滤网）

| 层级 | 时间框架 | 任务 | 核心指标 |
|------|---------|------|---------|
| **潮汐** | 周线 | 判断趋势方向，决定只做多/做空 | MACD柱状图、26周EMA |
| **波浪** | 日线 | 在趋势方向上找回调入场点 | 随机振荡器、Force Index |
| **涟漪** | 小时线 | 精确入场执行 | 追踪止损单、K线形态 |

**核心规则：潮汐向上时只做多，潮汐向下时只做空。**

### 趋势识别工具箱

| 工具 | 用法 | 来源 |
|------|------|------|
| 价格新高/新低 | 创新高=上升趋势确认 | Livermore、O'Neil |
| 20日/55日通道突破 | 突破N日最高价做多 | Dennis 海龟系统 |
| EMA方向 | 价格在EMA上方且EMA上升=上升趋势 | Elder |
| MACD柱状图方向 | 柱状图从负转正=趋势转多 | Elder |
| ADX | ADX>25=有方向性趋势 | Tharp 市场分类 |

### 自上而下分析框架（Livermore）

```
第一层：大盘趋势（牛市/熊市/震荡）
  ↓ 只在牛市做多，熊市空仓或做空
第二层：板块方向（资金流向哪些板块）
  ↓ 只做强势板块，不做弱势板块
第三层：个股选择（板块内的龙头股）
  ↓ 等待关键点突破后进场
```

## 心法四：安全边际——买得便宜是最大的保护

> "安全边际的功能在于，你不需要准确估计未来，只要买入价格足够低就行。"——Graham

### 估值工具箱

| 方法 | 公式/标准 | 适用场景 | 来源 |
|------|----------|---------|------|
| **Graham Number** | √(22.5 × EPS × 每股净资产) | 价值股筛选 | Graham |
| **PE×PB门槛** | PE×PB ≤ 22.5 | 综合估值过滤 | Graham |
| **防御型七条** | PE≤15, PB≤1.5, 流动比率≥2, 连续10年盈利... | 稳健选股 | Graham |
| **Net-Net策略** | 股价 ≤ 每股净流动资产 × 2/3 | 极端熊市捡烟蒂 | Graham |
| **成长股公式** | V = EPS × (8.5+2g) × (4.4/Y) | 评估成长股价值 | Graham |
| **CANSLIM** | 当季EPS增长≥25%, 年均≥25%, 相对强度前20%... | 成长股选股 | O'Neil |

### 逆向操作时机

| 市场状态 | 信号 | 操作 | 来源 |
|----------|------|------|------|
| 极度恐慌 | 市场PE < 历史10%分位 | 大量买入 | Graham "市场先生" |
| 恐慌 | PE < 历史25%分位 | 适度买入 | Graham |
| 正常 | PE 在25%-75%分位 | 持有 | — |
| 亢奋 | PE > 历史75%分位 | 适度卖出 | Graham |
| 极度亢奋 | PE > 历史90%分位 | 大量卖出 | Graham |

**关键区分（Steinhardt）**：逆向是不够的，你必须是对的。不是所有便宜的东西都值得买——要区分"便宜的好公司"和"价值陷阱"。

## 心法五：心理纪律——最大的敌人是自己

> "交易成功的关键是情绪纪律。如果智力是关键，那么赚钱的交易者会多得多。"——Tharp

### 四大心理敌人（Livermore）

| 敌人 | 表现 | 解药 |
|------|------|------|
| **无知** | 不懂就交易 | 学够再上场 |
| **贪婪** | 盈利后加大仓位、不设止盈 | 严格执行系统，连赢后缩仓 |
| **恐惧** | 该入场时犹豫、止损后不敢再交易 | 用R思维替代金额思维 |
| **希望** | 亏损时期待"会回来的"、不执行止损 | 止损是保护，不是认输 |

### 关键心理法则

```
1. 市场是一面镜子，放大你性格中的每一个弱点（Livermore）
2. 你交易的是你的信念，不是市场本身（Tharp）
3. 市场不知道你的存在，你只能控制自己的行为（Elder）
4. 错了不丢人，死扛才丢人（Jones）
5. 圣杯不在市场里，在你心中（Tharp）
6. 过程正确 + 结果亏损 = 正常波动，不要归咎于系统（Tharp）
7. 错过机会不亏钱，错误入场才亏钱（Elder）
```

### 连亏应对协议

```
连亏 3 笔 → 缩仓至正常仓位的 50%
连亏 5 笔 → 暂停交易 1-2 天，复盘交易日志
月度亏损达 6% → 当月停止交易
连亏期间禁止：
  × 加大仓位试图翻本
  × 更换交易系统
  × 追逐"内幕消息"
  × 因无聊而交易
```

### 交易日记（成长的阶梯）

每笔交易记录：
- 入场/出场价格和理由
- 止损位和调整记录
- 最大浮盈/浮亏
- 情绪状态（平静/焦虑/兴奋/恐惧）
- 执行评分（是否严格按系统操作）
- 教训总结

## 心法六：系统化交易——从艺术到工程

> "赚大钱的秘诀不在于买进卖出，而在于等待。"——Livermore

### 交易系统六要素（按重要性排序）

| 优先级 | 要素 | 占比 | 说明 |
|--------|------|------|------|
| 1 | 信念系统 | — | 系统必须与你的性格和信念一致 |
| 2 | 仓位管理 | 30% | 决定每笔交易的风险敞口 |
| 3 | 出场策略 | 25% | 止损+移动止损+止盈规则 |
| 4 | 市场筛选 | 20% | 什么条件下可以考虑交易 |
| 5 | 入场信号 | 15% | 具体触发交易的信号 |
| 6 | 执行纪律 | 10% | 持续按规则执行 |

**反直觉洞察**：大多数人把90%精力放在入场信号上，但入场只占15%的重要性。

### 策略类型与市场匹配（Tharp）

| 市场类型 | 特征 | 适用策略 | 仓位 |
|----------|------|---------|------|
| 方向性平静 | 明确趋势，低波动 | 趋势跟踪、突破 | 正常或偏大 |
| 方向性波动 | 强趋势伴随大幅震荡 | 趋势跟踪（宽止损） | 缩小 |
| 横盘平静 | 区间震荡，低波动 | 均值回归、区间交易 | 正常 |
| 横盘波动 | 频繁假突破 | 观望或极小仓位 | 极小或空仓 |

**关键原则：当市场类型与你的系统不匹配时，停止交易。**

### 金字塔加仓法（Livermore + Dennis）

| 步骤 | 条件 | 加仓比例 | 止损调整 |
|------|------|---------|---------|
| 首次建仓 | 信号触发 | 总仓位的 25% | 设定初始止损 |
| 第一次加仓 | 盈利 +1R | 总仓位的 20% | 移至盈亏平衡 |
| 第二次加仓 | 盈利 +2R | 总仓位的 15% | 移至 +1R |
| 第三次加仓 | 盈利 +3R | 总仓位的 10% | 移至 +2R |

**铁律：亏损永不加仓。回到平均成本则全部清仓。**
